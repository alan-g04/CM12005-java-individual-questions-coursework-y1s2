Implement a modified Vigenère cipher in Java to encrypt a message of any length. A Vigenère cipher is an example of a polyalphabetic substitution cipher. To encrypt a message, you first choose a keyword to use and then trim or repeat it until it is the same length as the message you wish to encode, which is then reversed. For example, if you choose the keyword LEMON and the message ATTACKATDAWN, you would have:

Message:  A T T A C K A  T D A W N

Key:    E L N O M E L N O M E L

Next, each letter of the repeated keyword corresponds to the cipher alphabet (i.e. row) used to code each letter of the message based on the Vigenère square below. The letter in the original text is then replaced by the letter in the corresponding index of the cipher alphabet. That is, for the first two letters of the message example above, 'A' is coded as 'E' i.e. the 5th index of the cipher alphabet 'E', and 'T' is coded as 'E' i.e. the 12th index of cipher alphabet 'L' etc. Repeating these steps the fully coded message is - EEGOOOLGRMAY.
